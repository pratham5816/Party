<entity name="Bike" operation="one/create/list/store">

list - performs select * from table;
create - insert a new record;
store - update a existing record;
one - perfroms select * from table where [] = [];

<view-entity> - used for a virtual database view.
                its kind of a sql join where we are joining tables so that 
                everytime we don't have to write complex query.
                - increase performance.

cache=never/true - we can set this while creating entities that if we want to 
                    cache it in main memory or we want to qeury db everytime.
                    cache="true" will store all the records in main memory.

<description> tag - Its there for devs for ease of understanding. we can mention 
                    ex- what a field is about ? 
                    it will not reflect in database / api
                    it will be there in codebase / swagger ui .
